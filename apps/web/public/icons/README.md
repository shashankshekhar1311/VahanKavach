# VahanKavach PWA icons

These marks are **private product branding** (abstract shield + “VK” monogram).

## Raster (install / home screen)

| File | Size | Purpose |
|------|------|---------|
| `icon-192.png` / `icon-512.png` | 192 / 512 | `purpose: "any"` |
| `icon-maskable-192.png` / `icon-maskable-512.png` | 192 / 512 | `purpose: "maskable"` (full-bleed `#09090b`, emblem in ~80% safe zone) |
| `../apple-touch-icon.png` | 180 | iOS Add to Home Screen (opaque) |

SVG sources remain for scalable entries in `manifest.json`.

They intentionally **do not** include:

- Ashoka Chakra
- Lion Capital / national emblem
- Police badges, stars, or government seals
- MoRTH / Parivahan / state transport logos

Primary store category: **Automotive & Fleet Management**.
